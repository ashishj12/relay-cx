# UI walkthrough

The 10-page relay-ui-guide.pdf contains an index and nine actual application views. Source PNGs are in ui/. Open the PDF locally to use page navigation and bookmarks. These are screenshots of this implementation, not speculative screens. Captures use Reviewer mode; genuine ADK execution is separately recorded in evidence/current/live-gemini-evidence.json.

For an animated demo: sign in as Alex, ask about the plan, clarify a service problem, request a case, approve it and inspect the receipt. Open Agent Studio to explain the configured agents and recorded invocations. Sign in as support.agent to run all eight scenarios, inspect integration metrics and open an execution trace. Keep the mode labels and approval step visible.

The PDF uses digital page sizes that preserve screenshot legibility. Desktop and mobile PNGs can be imported directly into motion software. The build_ui_guide.py utility needs optional reportlab and Pillow packages; they are not API dependencies.
